# Public APIs

A collective list of free APIs for use in software and web development.

## APIs

### Development

| API | Description | Auth | HTTPS | CORS |
| --- | --- | --- | --- | --- |
| [GitHub](https://api.github.com) | GitHub API for accessing repositories, users, and more | OAuth | Yes | Yes |
| [JSONPlaceholder](https://jsonplaceholder.typicode.com) | Fake online REST API for testing and prototyping | No | Yes | Yes |
| [ReqRes](https://reqres.in) | A hosted REST-API ready to respond to your AJAX requests | No | Yes | Yes |
